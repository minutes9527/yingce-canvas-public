# 视频拆解

当前能力：候选抽帧、语音转写、人工确认后的画面与提示词分析，以及画布中的 视频拆解节点。

浏览器只会把当前用户授权的已保存视频交给受信任本机适配器；候选帧必须经人工确认后，才会提交画面分析。当前抽帧使用相邻帧、已保留帧、时序切镜、渐变转场/曝光和小范围运动变化估计，并为每个候选输出综合分数、分项分数和触发原因；单帧闪光会被时序检查抑制。人物跟踪、姿态、OCR 与字幕语义检测仍属后续能力。

候选帧、转录与人工确认后的逐帧分析构成固定流程。候选抽帧是本地必经步骤；语音转写是增强信息：系统渠道拒绝转写时，候选帧仍会保留并提示具体失败，用户可以继续人工确认和逐帧分析。修正渠道或模型后，可在同一复核节点单独重试转写，不重新扫描视频、不丢失候选帧或已选画面。视频源变更或页面刷新后，未完成的本地处理需要重新准备。分析结果会作为带证据状态的文本资源交给下游 Skill。

人工确认完成后，可使用“导出已确认分镜到画布”将每一帧作为独立图片节点写回当前画布。导出会保留原始帧比例、时间点、帧序号和原视频来源；同一复核节点重复导出不会创建重复图片。未确认、预览读取失败或原视频已变化的帧不可导出。

分析完成后，还可以选择“生成轻量分镜复刻”。宿主会复用或创建确认帧图片，生成一个独立的 FrameScript 复刻节点；它按序号展示镜头、时长、图片提示词、视频提示词、台词和参考帧，并保留上游接入的参考资产。节点可按单个镜头或全部镜头“导入图片生成”，为每个序号创建一个独立的图片生成节点，自动连入参考资产；创建后由用户分别点击生成，不自动消耗额度。不包含完整分镜脚本的生成、合并或批量渲染功能。原有分镜节点保持不变。

候选输出中的 `detectors` 会列出实际运行的画面检测器：相邻/保留帧差异、时序切镜、渐变转场/曝光和小范围运动变化。运动方向只描述画面中的局部位移，不用于判断摄像机或人物身份。人物身份、姿态、OCR 与字幕语义仍需后续模型适配，当前不会伪装成已实现。

第 4 批已加入语义检测器扩展协议。未来的本地或 FrameScript 检测器可以按时间点提供人物/产品、姿态、镜头和字幕信号；宿主会按采样时间安全合并，并在候选帧中保留触发原因与分项分数。当前未启用真实语义检测器，现有扫描行为不变。

第 5 批适配 FrameScript 的可选结构化 `semantic_signals` 返回字段。只有带有效帧索引、信号类型、分数、原因和检测器 ID 的数据才会进入结果；普通描述文本不会被当作 OCR、姿态或人物检测结论。

`timeline`、`compile`、`render`、`export` 仅为预留能力，不可执行，也不代表可以输出 MP4。完整接口见 [docs/interface.md](docs/interface.md)。

## Canvas 系统渠道

Canvas 中的“视频拆解”不连接本机 FrameScript Assistant，也不读取 `127.0.0.1:8001`。视频只由宿主通过已授权媒体服务读取；候选帧抽取在 Canvas 内完成。

插件设置中的“关联系统渠道”决定画面分析和图片提示词的出口。语音转写默认沿用该渠道，也可单独选择一个支持 OpenAI 兼容 `/audio/transcriptions` 的系统渠道；这适用于视觉模型与转写模型由不同服务提供的情况。所有请求仍经 Canvas 的系统渠道代理发送；API Key、上游地址、协议和计费都由 `/admin/channels` 统一管理，插件本身不保存或接触 API Key。

FrameScript Assistant 是独立项目，不属于 Canvas 画布节点运行时的依赖。即使本机 Assistant 未启动，Canvas 节点也不应尝试访问本机地址；只要系统渠道有效且已选择对应模型，就可以在画布中运行分析流程。
